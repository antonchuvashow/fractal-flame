# Fractal Flame Generator

Программа для генерации изображений фрактального пламени на основе алгоритма Chaos Game.

## Возможности

### Основной функционал

* **Два режима работы** — однопоточный и многопоточный с настраиваемым количеством потоков
* **Цветная генерация** — реализован цветной алгоритм рендеринга фрактального пламени
* **Богатый набор трансформаций** — реализовано 5+ функций преобразования из [оригинальной статьи](https://flam3.com/flame_draves.pdf)
* **Гибкая конфигурация** — поддержка CLI-аргументов, JSON-файлов и значений по умолчанию
* **Валидация параметров** — входные данные проверяются с выводом понятных сообщений об ошибках
* **Логирование** — прогресс генерации отображается в консоли с процентом выполнения

### Дополнительные возможности

* **Логарифмическая гамма-коррекция** — настраиваемая коррекция яркости по формуле `color = pow(color, 1.0 / gamma)`
* **Симметрия** — поддержка N-кратной симметрии с поворотом точек на 360/N градусов

### Выходные данные

Результат работы — изображение в формате **PNG**, цветовой диапазон **RGB**, **8 бит на канал**.

## Использование

### Параметры командной строки

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `-w`, `--width` | int | `1920` | Ширина изображения |
| `-h`, `--height` | int | `1080` | Высота изображения |
| `--seed` | long | `5` | Начальное значение генератора |
| `-i`, `--iteration-count` | int | `2500` | Количество итераций |
| `-o`, `--output-path` | string | `result.png` | Путь для сохранения |
| `-t`, `--threads` | int | `1` | Количество потоков |
| `-g`, `--gamma-correction` | bool | `false` | Включить гамма-коррекцию |
| `--gamma` | double | `2.2` | Значение гаммы |
| `-s`, `--symmetry-level` | int | `1` | Уровень симметрии (N ≥ 1) |
| `-ap`, `--affine-params` | string | — | Аффинные преобразования |
| `-f`, `--functions` | string | — | Функции трансформации |
| `--config` | string | — | Путь к JSON-конфигу |

### Формат аффинных параметров

```
<a>,<b>,<c>,<d>,<e>,<f>/<a>,<b>,<c>,<d>,<e>,<f>/...
```

Где:
- `a` — масштаб/вращение X
- `b` — сдвиг-смешивание X от Y
- `c` — сдвиг по X
- `d` — смешивание Y от X
- `e` — масштаб/вращение Y
- `f` — сдвиг по Y
- `/` — разделитель преобразований

### Формат функций трансформации

```
<функция>:<вес>,<функция>:<вес>,...
```

Пример: `swirl:1.0,horseshoe:0.8`

### Примеры запуска

```shell
# Базовый запуск
./bin/fractalflame --seed 32 -i 5000 -f swirl:1.0,horseshoe:0.8 -t 2

# С гамма-коррекцией
./bin/fractalflame -i 10000 -t 4 -g --gamma 2.4

# С симметрией
./bin/fractalflame -i 5000 -t 4 -s 6 -f swirl:1.0

# С JSON-конфигом
./bin/fractalflame --config config.json
```

```json

  "size": {

    "height": 1080

  "iteration_count": 2500,
  "output_path": "result.png",
  "threads": 4,
  "seed": 2.1324512,
  "gamma_correction": true,
  "gamma": 2.2,
  "symmetry_level": 1,
  "functions": [
    {
      "name": "swirl",
      "weight": 1.0
    },
    {
      "name": "horseshoe",
      "weight": 0.7
    }
  ],
  "affine_params": [
    {
      "a": 1.0,
      "b": 1.0,
      "c": 1.0,
      "d": 1.0,
      "e": 1.0,
      "f": 1.0
    },
    {
      "a": 0.3,
      "b": 1.0,

      "d": 0.4,
      "e": 1.0,
      "f": 1.0
    }
  ]
}
```

1. **CLI-аргументы** (высший приоритет)
2. **JSON-файл**
3. **Значения по умолчанию**

## Реализованные трансформации

| Название | Описание |
|----------|----------|
| `linear` | Линейное преобразование |
| `sinusoidal` | Синусоидальное преобразование |
| `spherical` | Сферическое преобразование |
| `swirl` | Спиральное закручивание |
| `horseshoe` | Подковообразное преобразование |
| `polar` | Полярное преобразование |
| `handkerchief` | Преобразование "платок" |
| `heart` | Сердцевидное преобразование |
| `disk` | Дисковое преобразование |
